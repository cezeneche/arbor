# Nucleos Agent Team

## Reporting Structure
```
Steve Jobs (CEO)
├── Bill Bernbach     → Marketing
├── Dieter Rams       → Design
├── Taiichi Ohno      → Studio Operations
├── Alan Kay          → Product Architecture
├── Joe Girard        → Sales
├── Donald Knuth      → Software Engineering
└── Kelly Johnson     → Project Management
    └── James Bach    → Testing
```

## How to Invoke
Mention the agent by name or role in your request:
- "Review this as Jobs" / "CEO review"
- "Write copy as Bernbach" / "Marketing review"
- "Design audit as Rams"
- "Operations check as Ohno"
- "Architecture review as Kay"
- "Draft outreach as Girard"
- "Code review as Knuth"
- "Sprint plan as Johnson"
- "Test this as Bach"

All final decisions require Jobs's approval.
