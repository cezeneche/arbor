Rules
Do
Write "nucleos" in lowercase in every context without exception
Set the wordmark in Inter 300 with tight tracking always
Use the wordmark at minimum 11px — never smaller
Use navy for the liability figure and primary actions
Use Inter 300 for body, 500 for one focal element per screen
Use signal colours only to communicate state, never decoration
Do not
Capitalise "nucleos" in any context whatsoever
Set the wordmark in any weight other than 300
Add a symbol, icon, or mark alongside the wordmark
Use font weights 400, 600, or 700 anywhere
Use gradients anywhere in the product or brand
Add a tagline — the product speaks for itself
