# EU CBAM Transitional Period Default Values

**Source:** European Commission, DG TAXUD, 22 December 2023  
**Coverage:** CBAM Transitional Period — 1 October 2023 to 31 December 2025  
**Authority:** Commission Implementing Regulation (EU) 2023/1773, Art. 4(3)  
**Methodology:** JRC 2023 world-average weighted by production volumes  
**Unit:** tCO2e per tonne of goods (tCO2e/t)

These values are the official published defaults importers must use when actual embedded emissions from the producing installation are unavailable. From 2026 onwards, a new set of default values applies (country-specific averages with mark-ups). This document covers the transitional set only.

## 6. Indirect Emissions for Non-Electricity Goods

For determining indirect embedded emissions, the default approach is:

```
Indirect_tCO2e = electricity_consumed_MWh × grid_emission_factor_tCO2e_per_MWh
```

Grid emission factors are published per country in the CBAM Transitional Registry.  
Source: IEA 5-year average emission factors (2016–2020) for approximately 150 countries.  
World average fallback: 0.493 tCO2e/MWh.  
Countries with very high renewable share are assigned zero.

These country-specific electricity factors are available through the EU CBAM Transitional Registry and are not reproduced in full here.

## 8. Application Rules

**Hierarchy for use of default values during transitional period:**

- **Q4 2023, Q1 2024, Q2 2024** (first three quarterly reports): Default values may be used without quantitative limit.
- **Q3 2024 through Q4 2025**: Defaults may only be used for complex goods, limited to 20% of total embedded emissions. Direct use of defaults counted as "estimation."
- **From 1 January 2026**: Only EU method (actual measured emissions per EU 2023/1773) is accepted. These transitional defaults no longer apply for EU CBAM.

**UK CBAM note:** The UK CBAM begins 1 January 2027 with no transitional period. HMRC will publish separate UK default values ahead of 2027. Until then, this EU transitional table is used as the reference benchmark for engineering plausibility checks only.

**Default value mark-ups (definitive phase, EU only, from 2026):**
- 2026: 10% mark-up on country-average baseline
- 2027: 20% mark-up
- 2028+: 30% mark-up

These mark-ups apply to the 2026 definitive-phase default values (country-specific, not the world-average values in this document).

---

## 9. Scope and Coverage

Sectors covered by this default values document:
- Iron and steel (CN chapters 26 precursors, 72–73)
- Cement (CN chapters 25, 2523)
- Fertilisers (CN chapters 28, 31)
- Aluminium (CN chapter 76)
- Hydrogen (CN 2804)
- Electricity (CN 2716) — separate country-specific factors via CBAM Registry

**Not covered:** Scrap (7204, 7602) is explicitly excluded from CBAM scope in both EU and UK regimes.
