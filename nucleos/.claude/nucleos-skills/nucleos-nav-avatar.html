Behaviour rules
Only one dropdown open at a time — opening another closes this one.
Click anywhere outside the dropdown closes it immediately.
Escape key closes the dropdown from any state.
Delete confirmation state resets when the dropdown closes — user must re-click Delete to see it again.
The dropdown does not close when the notification toggle is clicked.
On mobile below 768px: the dropdown anchors to the right edge of the viewport with 16px inset.
